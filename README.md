# dotaplatim

Proyecto Node.js de **PLATIM (Dotaindustria Platim)** — empresa colombiana de dotaciones, uniformes, calzado de seguridad y Elementos de Protección Personal (EPP).

Complementa el sitio corporativo estático [xentristech/platim](https://github.com/xentristech/platim) (en vivo en [www.platim.co](https://www.platim.co)) con funcionalidad de aplicación (por definir: catálogo, cotizaciones, gestión de dotaciones, etc.).

## Stack

- Node.js / JavaScript

## Referencias

- Sitio en vivo: https://www.platim.co
- Repo del sitio estático: https://github.com/xentristech/platim
